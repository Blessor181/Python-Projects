# Python Email Simulator

## Overview
A beginner Python project that simulates basic email communication between users. Users can send emails, receive messages in their inboxes, read emails and delete them.

## Features
- Send emails between users.
- Store incoming emails in the recipient's inbox.
- Display email summaries, including sender, subject, timestamp and read status.
- Read full email messages and mark them as read.
- Delete emails from an inbox.
- Validate email numbers and handle empty inboxes.

## Technologies
- Python 3
- `datetime` module

## Project Structure
The program uses three classes:

- **Email:** Stores email details, records the timestamp and manages read status.
- **User:** Represents a user and provides methods for sending emails and managing their inbox.
- **Inbox:** Stores received emails and handles listing, reading and deleting them.

## Python Concepts Practised
This project helped me practise object-oriented programming, classes, objects, constructors, instance attributes, methods, list operations, conditional statements, loops, string formatting and input validation.

## Future Improvements
Possible improvements include adding an interactive menu, improving error handling and saving emails between program runs.

## How to Run
Run the Python file containing the program using Python 3

```bash
python main.py
```
